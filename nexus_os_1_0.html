LANGUAGE SPECIFICATION

NEX Language

A tiny fictional language designed for this simulation.

01 · Print text

Use say to display a message.

say "Hello from NEXUS!"
say "This is my first script."

02 · Variables

Use let to store a value and $name to insert it into text.

let creator = "Operator"
let level = 1
say "Creator: $creator"
say "Level: $level"

03 · Math

let score = 12
calc score + 8
say "Score is $score"

04 · Simulated system actions

wait 300
notify "Build complete"
set status = "online"
say "Status: $status"

05 · Comments

# Lines beginning with # are comments
say "Boot sequence starting..."
say "Boot sequence complete."

06 · Run scripts

Save code as a .nex file in Code Studio, then press Run script or type run hello.nex in Terminal.

Language limits

NEX is a small educational interpreter. It does not execute JavaScript, shell commands, network requests, or files on your device.
